### 🚀 About Me

Senior DevOps / SRE Engineer focused on building resilient, scalable cloud infrastructure and self-healing CI/CD pipelines.

- ☁️ **Cloud Platform:** Designing and operating multi-cluster **Azure (AKS)** environments.
- 🏗️ **Infrastructure as Code:** Immutable infrastructure with **Terraform**, **Terragrunt**, and **Ansible**.
- 🔄 **CI/CD Orchestration:** End-to-end continuous integration and delivery using **GitLab CI** and **GitHub Actions**.
- ☕ **Backend Integration:** Deep hands-on experience with **Java / Spring Boot** microservices and **Kafka / RabbitMQ** messaging.
- 📈 **Observability & Reliability:** Full-stack monitoring and log aggregation with **ELK Stack**, **Grafana**, and **Loki**.
